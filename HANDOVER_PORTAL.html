1. Developer Handover Guide

This document outlines the technical stack and integration plan for moving the current project to a Django + React architecture.

Current Stack

  • • React.js (Vite)
  • • Tailwind CSS
  • • Recharts / Framer Motion
  • • Firebase (Real-time DB)

Target Stack

  • • Django + DRF
  • • PostgreSQL
  • • JWT Authentication
  • • React Frontend (Preserved)

Transfer Steps

  1. Backend Rewrite: Move Firebase Logic to Django Models (Notice, Leaderboard, etc).
  2. API Endpoints: Create REST endpoints using Django REST Framework.
  3. Frontend Hookup: Replace Firebase SDK listeners with Axios/Fetch calls.
  4. Auth Migration: Replace Google Popup auth with Django Token authentication.
